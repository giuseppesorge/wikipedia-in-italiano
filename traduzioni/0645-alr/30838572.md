# Alstermo IF (disambiguazione)

*[Voce originale su Wikipedia](https://en.wikipedia.org/wiki/Alstermo_IF_%28disambiguation%29)*

**Alstermo IF** è un club sportivo svedese situato ad Alstermo, con diverse sezioni:

* Alstermo IF Handboll, sezione pallamano
* Alstermo IF Fotboll - sezione calcio
* Alstermo IF Skidor, sezione sci
* Alstermo IF Gymnastik, sezione ginnastica
* Alstermo IF Orientering, sezione orienteering
