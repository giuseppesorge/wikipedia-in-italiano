# Scala Funzionale di Valutazione dell'ALS - Rivista

La sclerosi laterale amiotrofica (ALS) è una malattia neurodegenerativa che colpisce tipicamente adulti di età compresa tra 54 e 67 anni, sebbene chiunque possa ricevere una diagnosi. Le persone diagnosticate con ALS vivono in media 2-4 anni dopo la diagnosi a causa della rapida progressione della malattia. La progressione e la gravità dell'ALS sono valutate dai medici mediante la **Scala Funzionale di Valutazione dell'ALS**, che è stata rivista e prende il nome di **ALSFRS-R**.

## Criteri

L'ALSFRS-R comprende 12 domande che ricevono un punteggio da 0 a 4. Un punteggio di 0 indica assenza di funzione, mentre un punteggio di 4 indica funzione completa. Questa scala è stata utile ai medici per diagnosticare i pazienti, misurare la progressione della malattia e ai ricercatori per selezionare i pazienti per studi clinici e misurare gli effetti potenziali di un trial.

La scala ALSFRS-R presenta alcune limitazioni, poiché non è utile confrontare i punteggi di persone con diverso tipo di esordio. In ALS il tipo di esordio principale è bulbare, seguito da ALS ad esordio agli arti, che descrive la regione dei motoneuroni colpiti per prima. Gli individui possono anche presentare ALS ad esordio respiratorio, ma questo accade molto raramente. Poiché esistono tre diversi tipi di ALS, i punteggi ALSFRS-R sono spesso raggruppati per categoria in base al tipo di esordio.

Poiché esistono tre principali percorsi di progressione, le domande sono anche suddivise in relazione ai tipi di esordio. Le domande 1-3 riguardano l'esordio bulbare, le domande 4-9 l'esordio agli arti e le domande 10-12 l'esordio respiratorio. I successivi sviluppi dell'ALSFRS-R includono una versione estesa (ALSFRS-EX) per mitigare l'effetto pavimento e una versione con note esplicative, particolarmente adatta all'autovalutazione (ALSFRS-R-SE), che presenta un forte accordo con l'SOP armonizzato per la valutazione basata su intervista.

## Progressione

I punteggi ALSFRS-R calcolati al momento della diagnosi possono essere confrontati con i punteggi nel tempo per determinare la velocità di progressione. Il tasso di variazione, detto pendenza ALSFRS-R, può essere utilizzato come indicatore prognostico.

Sebbene il punteggio ALSFRS-R sia un indicatore prognostico riconosciuto, è più utile confrontare vari indicatori, inclusa la capacità vitale forzata (FVC%) e il Sickness Impact Profile (SIP), per aumentare l'accuratezza di una prognosi.

Mettere in relazione il punteggio ALSFRS-R con i criteri di stadiazione è utile anche nel determinare la prognosi. Il sistema di King si basa sulla diffusione clinica della malattia come misura di progressione, mentre la Stadiazione Milano-Torino (MiToS) utilizza i sottopunteggi prodotti dall'ALSFRS-R per definire gli stadi.

## Domande

Le domande utilizzate per determinare il punteggio ALSFRS-R di un individuo sono elencate di seguito.

|  |  |
| --- | --- |
| *1. Linguaggio* | |
| 4 | Processi vocali normali |
| 3 | Disturbo del linguaggio rilevabile |
| 2 | Intelligibile se ripetuto |
| 1 | Linguaggio combinato con comunicazione non verbale |
| 0 | Perdita del linguaggio utile |
| *2. Salivazione* | |
| 4 | Normale |
| 3 | Leggero ma definito eccesso di saliva in bocca; può avere scialorrea notturna |
| 2 | Saliva moderatamente eccessiva; può avere minima scialorrea |
| 1 | Marcato eccesso di saliva con leggera scialorrea |
| 0 | Marcata scialorrea; richiede costantemente tessuto o fazzoletto |
| *3. Deglutizione* | |
| 4 | Abitudini alimentari normali |
| 3 | Primi problemi alimentari — occasionali soffocamenti |
| 2 | Cambiamenti nella consistenza della dieta |
| 1 | Necessita di alimentazione tramite sonda supplementare |
| 0 | NPO (alimentazione esclusivamente parenterale o enterale) |
| *4. Scrittura* | |
| 4 | Normale |
| 3 | Lento o disordinato: tutte le parole sono leggibili |
| 2 | Non tutte le parole sono leggibili |
| 1 | Capace di impugnare la penna ma incapace di scrivere |
| 0 | Incapace di impugnare la penna |
| *5a. Tagliare il cibo e maneggiare le posate (pazienti senza gastrostomia)?* | |
| 4 | Normale |
| 3 | Alquanto lento e goffo, ma nessun aiuto necessario |
| 2 | Può tagliare la maggior parte dei cibi, sebbene goffo e lento; alcuni aiuti necessari |
| 1 | Il cibo deve essere tagliato da altri, ma riesce ancora a mangiare lentamente |
| 0 | Ha bisogno di essere nutrito |
| *5b. Tagliare il cibo e maneggiare le posate (scala per pazienti con gastrostomia)?* | |
| 4 | Normale |
| 3 | Goffo ma capace di eseguire tutte le manipolazioni in modo indipendente |
| 2 | È necessario un po' di aiuto con chiusure e fermagli |
| 1 | Fornisce un aiuto minimo all'assistente |
| 0 | Incapace di eseguire qualsiasi aspetto del compito |
| *6. Vestirsi e igiene personale* | |
| 4 | Funzione normale |
| 3 | Autocura completa e indipendente con sforzo o efficienza diminuita |
| 2 | Assistenza intermittente o metodi alternativi |
| 1 | Ha bisogno di assistente per l'autocura |
| 0 | Totale dipendenza |
| *7. Voltarsi a letto e sistemare le coperte* | |
| 4 | Normale |
| 3 | Alquanto lento e goffo, ma nessun aiuto necessario |
| 2 | Riesce a voltarsi da solo o a sistemare le lenzuola, ma con grande difficoltà |
| 1 | Riesce a iniziare, ma non a voltarsi o sistemare le lenzuola da solo |
| 0 | Completamente incapace |
| *8. Camminare* | |
| 4 | Normale |
| 3 | Difficoltà di deambulazione precoce |
| 2 | Cammina con assistenza |
| 1 | Movimento funzionale non ambulatoriale |
| 0 | Nessun movimento intenzionale delle gambe |
| *9. Salire le scale* | |
| 4 | Normale |
| 3 | Lento |
| 2 | Leggera instabilità o affaticamento |
| 1 | Ha bisogno di assistenza |
| 0 | Non riesce |
| *10. Dispnea (nuovo)* | |
| 4 | Assente |
| 3 | Si verifica quando si cammina |
| 2 | Si verifica con uno o più dei seguenti: mangiare, fare il bagno, vestirsi (ADL) |
| 1 | Si verifica a riposo; difficoltà di respirazione quando seduto o sdraiato |
| 0 | Difficoltà significativa; considera l'utilizzo di supporto respiratorio meccanico |
| *11. Ortopnea (nuovo)* | |
| 4 | Assente |
| 3 | Qualche difficoltà a dormire di notte a causa della mancanza di respiro |
|  | Non usa abitualmente più di due cuscini |
| 2 | Ha bisogno di cuscini extra per dormire (più di due) |
| 1 | Riesce a dormire solo seduto |
| 0 | Non riesce a dormire |
| *12. Insufficienza respiratoria (nuovo)* | |
| 4 | Assente |
| 3 | Uso intermittente di BiPAP |
| 2 | Uso continuo di BiPAP durante la notte |
| 1 | Uso continuo di BiPAP durante il giorno e la notte |
| 0 | Ventilazione meccanica invasiva mediante intubazione o tracheostomia |
