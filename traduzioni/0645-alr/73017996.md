# Alseika

*[Voce originale su Wikipedia](https://en.wikipedia.org/wiki/Alseika)*

**Alseika** è un cognome lituano. Tra le persone notevoli con questo cognome:

* Danielius Alseika
* Liudas Alseika (1887–1960), viaggiatore lituano, esperantista, appassionato di tradizioni locali, pedagogo
* Veronika Alseikienė (1883–1971), prima medica lituana
* Marija Birutė Alseikaitė, nome di nascita di Marija Gimbutas
